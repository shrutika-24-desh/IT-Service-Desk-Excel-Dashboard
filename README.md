# IT Service Desk – MIS Dashboard

## Project Overview
This project analyzes IT service desk tickets using Advanced Excel.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Excel Formulas

## Key Analysis
- Ticket Status Analysis
- Issue Type Analysis
- Priority Analysis
- Department Analysis
- SLA Performance
- Monthly Ticket Trend
- Agent Performance

## Key KPIs
- Total Tickets
- Closed Tickets
- Open/In Progress Tickets
- SLA Met %
- Average Resolution Hours
